# 说明

这几张图是当前系统（RM65-B + Gemini 336L 等效相机 + 气动打磨头）在不同深度相机噪声水平下的力控制输出结果，按建议阅读顺序编号。

## 文件对照

1. **01_噪声鲁棒性汇总曲线.png**：汇总图，横轴是相机单帧噪声大小，纵轴是感知精度/闭环力误差，一张图看全局趋势，建议先看这张建立整体印象。
2. **02_单档结果_噪声0mm_基线.png**：干净基线（相机没有额外噪声），力稳定在 8N 目标附近，std=0.152N。
3. **03_单档结果_噪声10mm_稳健.png**：中等噪声，表现跟基线几乎一样，系统稳健。
4. **04_单档结果_噪声15mm_临界.png**：明显退化的临界点——力的统计数字看着还行，但轨迹俯视图和高度曲线能看到机械臂后段明显跑偏（对应机械臂连杆撞到工件/底座的警告），安全系统这时候没有反应。
5. **05_单档结果_噪声20mm_安全跳闸.png**：噪声太大导致安全系统正确触发跳闸，力被拉到 0 并锁定，不再自动恢复打磨。
6. **06_四档力跟踪并排对比.png**：把上面 2-5 四档的"接触力跟踪"子图单独抽出来并排放在一张图里，共享同一个纵轴、图例统一放在最下方，方便直接对比四档之间的差异。

## 一句话结论

系统在 0-10mm 相机噪声范围内表现稳健；15mm 是最需要注意的临界区间（数字上不算太差，但已经出现未被现有安全机制捕捉到的机械臂结构碰撞）；20mm 时安全机制能正确介入并安全锁定。
